# The Backwards Clock

An analog clock that runs backwards and runs as a screensaver.


## History

In the early 1980's I walked into an office where someone had taped hand written numbers over the clock face.

They placed the numbers backwards; counter clockwise if you will.

When I asked why they did that, they told me to look closer; the clock was running backwards.

Sure enough, the second hand was going backwards.

The clock kept perfect time.

It takes a bit to get used to, but you will.


## Features

\- 12 hour analog clock

\- Sweeping second hand

\- Slowly drifts across screen

\- Black background

\- Think DVD screensaver
